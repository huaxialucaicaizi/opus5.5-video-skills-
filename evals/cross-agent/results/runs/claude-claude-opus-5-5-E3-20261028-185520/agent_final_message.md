流程图四步的具体内容：
1. **提问**：一个带问号的对话框。
2. **检索**：一叠资料页，扫描线扫过后有一段被高亮。
3. **增强**：段落和问题两条一起滑进「模型」方块。
4. **生成**：回答逐行写出，出现标记 [1]，再画一条标着「依据」的蓝色虚线，从回答连回被检索的那一段。
